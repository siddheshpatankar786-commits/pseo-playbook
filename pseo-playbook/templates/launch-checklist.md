# Launch checklist (per page)

- [ ] Page loads normally (status 200)
- [ ] Canonical points to the page itself
- [ ] No noindex in the page source
- [ ] Meta title and description present, within length, unique
- [ ] One H1
- [ ] Main content, FAQs and links visible in View Page Source
- [ ] No section repeated, no placeholder text left in
- [ ] Rich Results Test: schema valid, BreadcrumbList detected
- [ ] Breadcrumb visible, every level clickable and live
- [ ] Listed in the right section sitemap with current lastmod
- [ ] At least 3 to 5 internal links point to it from frequently crawled pages
- [ ] Indexing requested (priority pages) and change log updated
