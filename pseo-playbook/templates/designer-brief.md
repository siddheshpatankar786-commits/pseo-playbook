# Designer brief

One brief per page type.

**Hi [name], could we design the layout for the [page type] pages? The content will come
from a sheet, so each section needs to work with varying lengths.**

**What these pages are for:** who lands on them and what they should do next.

**Section order and treatment**
| # | Section | Unique / shared / optional / auto | Suggested treatment |
|---|---|---|---|
| 1 | Hero | unique | problem-first headline, short intro, CTA |
| 2 | | | |

**Must**
- Breadcrumb small, above the H1, same position on every page type.
- One responsive version of each section, not separate desktop and mobile copies.
- Optional sections hide cleanly when empty.
- Look clearly different from the other page types: [list them].
- No text inside images.

**Avoid**
- Long logo strips, the same testimonials on every page, generic "why choose us" blocks that
  take up most of the screen.
- Eyebrow labels above every heading.

**References:** [link] for [what to look at]; [link] for [what to look at].

**Content length ranges** (so the layout handles real rows): intro [x to y] words, pain
point cards [x to y] words each, FAQs [n to m] items.
